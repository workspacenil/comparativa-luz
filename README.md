# Comparativa de luz

Mini app movil para comparar tarifas de electricidad con el mismo consumo.

- `index.html`: app de un solo archivo, sin dependencias. Abrirla en el movil y listo.
- Compara las ofertas en PDF recibidas en noviembre de 2026 (TotalEnergies Clasica TE1 y Factor Energia 1126PROF1P), con impuestos (IVA 21% + impuesto electrico 5,113%).
- La oferta del chat no entra en el calculo: faltan unidades y documento.
- No contiene datos personales ni de contratos: solo precios publicos de las ofertas.

Repo privado.
